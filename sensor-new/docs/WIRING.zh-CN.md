# Smart-IoT "智能窗户" - 完整硬件接线指南

> 这份文档面向完全没有模拟/数字电路背景的人。
> 如果你从头到尾照着做，就不会损坏任何东西。先读一遍
> **黄金规则**，然后按步骤接线即可。

---

## 0. 我们要搭建什么

一块 ESP32-S3 开发板会模拟一个智能窗户节点。它会读取：

- **温度 + 湿度**（DHT11）
- **照度 / 亮度**（光敏电阻光照传感器）
- **空气质量** - 氨气、苯、乙醇、烟雾、CO2 等（MQ-135）

并通过这些部件执行动作：

- **蜂鸣器** - 当空气质量或读数超过阈值时报警
- **OLED 屏幕** - 显示读数和窗户状态（OPEN / CLOSED）
- **板载 RGB LED（GPIO48）** - 绿色 = 窗户打开，红色 = 窗户关闭

"窗户电机" 是**模拟出来的**：用户发送打开/关闭命令后，我们在 OLED 和 LED
上显示结果。这里不接舵机（你的器件清单里没有列出舵机）。

虽然软件会把这些传感器当成彼此隔离的独立传感器节点来处理，**但在物理接线上，
它们全部连接到同一块 ESP32-S3 开发板。**

## 1. 器件清单

| # | 器件 | 模块上印的接口 | 它如何和 MCU 通信 |
|---|------|----------------|-------------------|
| A | ESP32-S3-DevKitC-1（Goouuu, N16R8） | - | 主控大脑 |
| B | DHT11 温湿度传感器 | `DATA  VCC  GND` | 1 根数字信号线 |
| C | 光照传感器（光敏电阻） | `I/O  VCC  GND` | 1 根**模拟**信号线 |
| D | MQ-135 空气质量传感器 | `AO  DO  VCC  GND` | 1 根**模拟**信号线（AO） |
| E | OLED 0.96"（SSD1306） | `VDD  GND  SCK  SDA` | 2 根线（I2C 总线） |
| F | 蜂鸣器（有源，高电平触发） | `I/O  VCC  GND` | 1 根数字信号线 |

还需要：**面包板**、**公对母 / 公对公杜邦线**、**万用表**、电烙铁
（只有当某个模块没有焊好排针时才需要，见第 3 节）。

## 2. 黄金规则（先读一遍）

1. **所有模块都从 3.3V 电源轨供电，不要用 5V。**
   ESP32-S3 的引脚是 **3.3V 逻辑**。如果你用 5V 给传感器供电，它的信号/数据
   输出也可能变成约 5V，这会**永久损坏** ESP32 引脚。所有模块都用 **3.3V**
   供电，就能保证所有信号不超过 3.3V，完全安全。（这是最重要的一条规则。）

2. **USB 线连接时，绝对不要插拔杜邦线。**
   永远按这个顺序做：先接线 -> 仔细检查 -> *然后* 插 USB。

3. **信号线直接接 GPIO，电源和地接电源轨。**
   你会在面包板上做两条"电源轨"（一条 `+` 3.3V 线，一条 `-` GND 线）；
   每个模块的 VCC/GND 都接到这些电源轨。只有信号引脚是各自独立的。

4. **按标签接线，不要按颜色接线。** 杜邦线颜色没有意义，请只看模块上印的标签
   （VCC、GND、DATA 等）。

5. **MQ-135 会发热，而且需要预热。** 金属外壳变热是正常现象。它需要通电几分钟
   （最好更久）后读数才会稳定。不要触碰发热的金属环。

---

## 3. 模块需要焊接吗？

看每个模块的 3/4 针排针位置：

- 如果**金属针脚已经伸出来了** -> 不需要焊接，直接接杜邦线即可。
  （大多数套件模块出厂时已经焊好排针。）
- 如果你只看到**空孔** -> 必须把小排针条焊进这些孔里，这样才有地方接线。

你**不需要**在面包板或 ESP32 上焊任何东西，它们都使用可插拔杜邦线。所以焊接最多
只是把排针焊到裸模块上。如果你的所有模块都已经有针脚，可以完全不用电烙铁。

## 4. 理解 ESP32-S3 开发板布局

把开发板拿在手上，让**两个 USB-C 口朝向你（在底部）**，天线/屏蔽罩在顶部。
板子两侧各有一排引脚：

- **左排，从上到下：** `GND, 3V3, RST, IO4, IO5, IO6, IO7, IO15, IO16,
  IO17, IO18, IO8, IO19, IO20, IO3, IO46, IO9, IO10, IO11, IO12, 3V3`
- **右排，从上到下：** `GND, IO1, IO2, TXD(43), RXD(44), IO42, IO41,
  IO40, IO39, IO38, IO37, IO36, IO35, IO0, IO45, IO48, IO47, IO21, IO14, IO13,
  5V`

我们会用到的引脚（都比较好接）：

- `3V3` - 左上方（从上往下第 2 个引脚）。给所有模块供电。
- `GND` - 左上方（第 1 个引脚）和右上方（第 1 个引脚）。地。
- `IO1`, `IO2` - 右上区域 -> 两个**模拟**传感器。
- `IO4`, `IO5`, `IO6`, `IO7` - 左上区域 -> 数字信号 + I2C。
- `IO48` - 板载 RGB LED，**已经在 PCB 上接好了**（不需要杜邦线）。

> **为什么模拟信号用 IO1 / IO2？** ESP32-S3 上只有 **ADC1** 引脚（GPIO1-GPIO10）
> 可以在 Wi-Fi 开启时读取模拟电压。IO1 和 IO2 都是 ADC1 通道，所以适合接光照
> 传感器和 MQ-135。不要把模拟传感器挪到其他引脚。

## 5. 引脚映射（唯一准确信息源）

| 模块 | 模块引脚 | 接到 ESP32-S3 | 说明 |
|------|----------|---------------|------|
| **电源轨** | - | `3V3` -> 面包板 **+** 电源轨 | 一根杜邦线 |
| **地线轨** | - | `GND` -> 面包板 **-** 电源轨 | 一根杜邦线 |
| DHT11 | `VCC` | **+** 电源轨 | |
| DHT11 | `GND` | **-** 电源轨 | |
| DHT11 | `DATA` | **IO4** | 模块上已经有上拉电阻 |
| 光照传感器 | `VCC` | **+** 电源轨 | |
| 光照传感器 | `GND` | **-** 电源轨 | |
| 光照传感器 | `I/O`（模拟输出） | **IO1** | ADC1 - 亮度 |
| MQ-135 | `VCC` | **+** 电源轨 | |
| MQ-135 | `GND` | **-** 电源轨 | |
| MQ-135 | `AO`（模拟输出） | **IO2** | ADC1 - 气体水平 |
| MQ-135 | `DO` | *留空* | 不使用（我们读取模拟量） |
| OLED | `VDD` | **+** 电源轨 | |
| OLED | `GND` | **-** 电源轨 | |
| OLED | `SDA` | **IO6** | I2C 数据 |
| OLED | `SCK`（= SCL） | **IO7** | I2C 时钟 |
| 蜂鸣器 | `VCC` | **+** 电源轨 | |
| 蜂鸣器 | `GND` | **-** 电源轨 | |
| 蜂鸣器 | `I/O` | **IO5** | HIGH = 响 |
| RGB LED | （板载） | **IO48** | 不需要接线 - 窗户状态 |

这意味着接到 ESP32 的**信号/电源杜邦线一共 9 根**，再加上一些很短的电源轨分接线。

## 6. 分步骤组装

### Step 1 - 搭建电源轨

面包板两侧通常各有两条长线，通常用红色 `+` 和蓝色 `-` 标记。
任选其中一侧的一对电源轨。

1. 从 ESP32 **`3V3`** 跳线到面包板 **`+`** 电源轨。
2. 从 ESP32 **`GND`** 跳线到面包板 **`-`** 电源轨。

现在整条 `+` 电源轨都是 3.3V，整条 `-` 电源轨都是地。

### Step 2 - 放置模块

把每个模块插到面包板上（也可以先不固定，用公对母杜邦线连接）。对每个模块：

- 它的 **VCC/VDD** 引脚 -> 用杜邦线接到 **`+`** 电源轨
- 它的 **GND** 引脚 -> 用杜邦线接到 **`-`** 电源轨

对全部 5 个模块都这样做（DHT11、光照、MQ-135、OLED、蜂鸣器）。

### Step 3 - 连接信号引脚

每个信号一根杜邦线，直接接到对应 GPIO：

- DHT11 `DATA` -> **IO4**
- 光照传感器 `I/O` -> **IO1**
- MQ-135 `AO` -> **IO2**
- OLED `SDA` -> **IO6**
- OLED `SCK` -> **IO7**
- 蜂鸣器 `I/O` -> **IO5**

MQ-135 的 `DO` 保持不接。

### Step 4 - 上电前检查（万用表，见第 7 节）

### Step 5 - 插入 USB（用于烧录的 UART/左侧 USB-C 口）

## 7. 用万用表检查（每次上电前都做）

在 **USB 未插入** 的情况下，把万用表调到**通断 / 电阻（Ω）**档：

1. **电源没有短路：** 测 **`+`** 电源轨和 **`-`** 电源轨。它应该**不会**
   响（没有导通）。如果响了，说明有短路，上电前必须修好。
2. **每个 VCC 都连到电源轨：** 测某个模块的 VCC 引脚和 `+` 电源轨 ->
   应该响（已连接）。
3. **每个 GND 都连到地线轨：** 测某个模块的 GND 引脚和 `-` 电源轨 ->
   应该响。

然后插入 USB，把万用表切到**直流电压**档：

4. 测 `+` 电源轨（红表笔）到 `-` 电源轨（黑表笔） -> 应该读到 **约 3.3V**。
5. 如果某个模块的 VCC 没有约 3.3V，说明它的电源轨跳线松了。

如果以上检查都通过，接线就是安全且正确的。

## 8. 供电说明 / FAQ

- **用哪个 USB 口？** 使用**左侧 USB-C**（UART / CH340 那个）进行烧录和正常使用。
  它会给开发板供电，并承载串口控制台。
- **3.3V 电流够吗？** 够。这里所有模块从 USB 供电时的总电流都远低于板载稳压器
  的限制。MQ-135 加热器耗电最大，但 3.3V 下也没问题。
- **"但 MQ-135 通常不是 5V 吗？"** 没错，5V 会让它的加热器更热，读数也更接近
  标准使用方式。但在 5V 下，它的 `AO` 最高可能输出 5V，**这会损坏 IO2**。
  对这个课程/演示来说，**3.3V 是安全且正确的选择**，并且能正常工作。
  （进阶：如果以后确实需要 5V，必须在 `AO` 到 IO2 之间加电阻分压器 -
  这里不需要。）
- **蜂鸣器太小声？** 5V 下会更响。你*可以*只把蜂鸣器的 VCC 移到 `5V` 引脚
  （它的 `I/O` 只是逻辑输入，所以 3.3V HIGH 仍然可以安全触发）。这是可选的。
  如果不确定，就保持 3.3V。
- **DHT11 需要上拉电阻吗？** 你的模块上已经有板载上拉电阻（`R3` 元件）。
  不要再额外加。

## 9. 快速接线图（速查）

```text
ESP32-S3                       模块（所有 VCC->+3V3 电源轨，所有 GND->- 电源轨）
  3V3  ->  (+) 电源轨
  GND  ->  (-) 电源轨
  IO1  <----------------------- 光照传感器  I/O   （模拟亮度）
  IO2  <----------------------- MQ-135       AO    （模拟气体）
  IO4  <----------------------- DHT11        DATA  （温湿度）
  IO5  ------------------------> 蜂鸣器      I/O   （报警，HIGH=响）
  IO6  <---------------------->  OLED        SDA   （I2C 数据）
  IO7  ------------------------> OLED        SCK   （I2C 时钟）
  IO48（板载 RGB LED）= 窗户状态：绿色=打开 / 红色=关闭
```

完成这些接线并通过万用表检查后，`sensor-new/` 里的固件就会驱动这些引脚。
